# PstRotatorFrqShortcuts

AutoHotKey script for control of RX/TX doppler frequency in PstRotator
You need to install https://www.autohotkey.com/ and run this script via AutoHotKey
And of course you need PstRotator: https://www.qsl.net/yo3dmu/index_Page346.htm 

# What is this script doing?

1. Remap Space to toggle UP+DN button (start/stop rig doppler tracking) in Satellite Tracking windows in PstRotator
2. Remap UP and DOWN arrow keys to step 100 HZ up or down in satellite mode, both RX and TX frequency
3. Remap LEFT and RIGHT arrow keys to step 100 HZ up or down in satellite mode, only the RX frequency (works like RIT on the rig)
4. Esc key ends the script
